# 2024 Visual Programming (C#)

2024년 비주얼 프로그래밍 수업에서 작성한 C# Windows Forms 실습 코드입니다. 파일 앞의 번호는 예제 번호입니다.

## 주요 내용

| 번호 | 주제 |
| --- | --- |
| 001 ~ 004 | BMI 계산기: C, C++, C# 콘솔, Windows Forms 버전 |
| 005 ~ 012 | 로그인 화면, 기본 컨트롤, MessageBox, Label, CheckBox, RadioButton, 성적 계산기, ComboBox |
| 013 ~ 016 | 배열, 반복문, 난수 |
| 017 ~ 019 | Chart 컨트롤, 두 개의 ChartArea, 수학 함수 그래프 |
| 020 ~ 021 | 디지털 시계 · 타이머, 아날로그 시계 |
| 022 | Firebase 연동 (FireSharp) |
| 023 ~ 024 | 속성(property), 두 개의 폼 간 데이터 전달 |
| 025 | 시리얼 포트로 센서 값을 받아 실시간 차트로 모니터링 |

## 실행 방법

Visual Studio에서 Windows Forms 프로젝트를 만들고 해당 `.cs` 파일의 코드를 `Form1.cs`에 넣어 실행합니다.
